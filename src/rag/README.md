## Current RAG System

The current system is a safety-first Arabic RAG assistant for understanding the Saudi Labor Law. It uses a structured corpus of 249 legal articles, `BAAI/bge-m3` for Arabic semantic embeddings, FAISS for dense retrieval, `BAAI/bge-reranker-v2-m3` for reranking, and `Gemma 3 4B IT Q4_K_M` as the local generation model served through llama.cpp.

The pipeline works as follows:

User Query
→ BGE-M3 embedding
→ FAISS Top-3 retrieval
→ Cross-encoder reranking
→ Safety score gate
→ Best legal article only
→ Gemma generation
→ Deterministic article citation

The system can return three response types:

- `answer`: when the retrieved legal text is sufficiently relevant and directly supports an answer.
- `clarify`: when the question is within labor-law scope but important case-specific information is missing.
- `out_of_scope`: when the retrieved evidence is too weak or the question is outside the supported labor-law corpus.

A safety-first score policy is applied before generation:

- score `< 0.05` → reject / abstain
- score `0.05–0.15` → gray zone / abstain
- score `>= 0.15` → allow normal model routing

Only the highest-ranked reranked article is passed to Gemma to reduce ambiguity. Article citations are not generated by the LLM; they are attached deterministically from the retriever metadata.

The current 45-question evaluation achieved:

- Status Accuracy: **95.56%**
- Retrieval Accuracy: **97.37%**
- Answer Behavior Accuracy: **97.14%**
- Clarification Accuracy: **66.67%**
- Out-of-Scope Accuracy: **100%**
- Average Factual Coverage: **91.94%**
- Fully Factual Answer Rate: **80%**
- Wrong-Article Answers: **0**

The benchmark is now treated as a development set. Further prompt tuning on the same questions was stopped to avoid overfitting. Future validation will focus on unseen hold-out questions and real user queries.
